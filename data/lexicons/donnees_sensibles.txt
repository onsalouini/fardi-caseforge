# Vocabulaire de la DONNEE_SENSIBLE (guide v2, section 2 ; cas 5). Format : terme<TAB>type.
# « devise » : unité monétaire (avant ou après le montant) ; « multiplicateur » : million, mille… ;
# « reference » : mot qui introduit un numéro confidentiel (contrat, lot, facture, commande, rapport, matricule) ;
# « prefixe » : préfixe de code interne (« NCR-0932 », « PO-77120 ») ; les codes produit (« X-200 ») en sont exclus ;
# « montant_sensible » : nom de montant confidentiel (prix, coût, CA, marge, salaire) ;
# « nombre_lettres » : nombre écrit en toutes lettres devant un multiplicateur (« deux millions de dinars ») ;
# « plafond » : mot qui place un montant dans une contrainte (budget, plafond) : montant non sensible (cas 5).
